\# NJinterviewtool



A real-time AI interview assistant built with Python.



\## Features



\* Real-time speech transcription

\* Whisper speech recognition

\* AI-generated interview responses

\* Resume-aware answers

\* Dual audio input support



\## Installation



Clone the repository:



```bash

git clone git@github.com:VENNUNAGARAJ12/NJinterviewtool.git

cd NJinterviewtool

```



Install dependencies:



```bash

pip install -r requirements.txt

```



Run:



```bash

python main.py

```
